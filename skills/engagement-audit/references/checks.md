# Engagement Audit Checks

## 1. First-screen Orientation

### Questions to Answer
- What is this?
- Who is it for?
- What does it offer?
- Why is it useful?
- What should the visitor do next?

### Observable Signals
- H1 heading
- Subheading or tagline
- Visible descriptive text
- Primary CTA (call-to-action)
- Navigation structure
- Product/service explanation

### Severity Rules
- **Critical**: No clear value proposition
- **High**: Missing primary CTA
- **Medium**: Unclear target audience
- **Low**: Missing secondary information
- **Info**: Clear orientation signals

## 2. Navigation

### Checks
- Navigation presence
- Major navigation labels
- Important section links
- Broken navigation links
- Mobile navigation
- Search functionality

### Severity Rules
- **Critical**: No navigation
- **High**: Broken navigation links
- **Medium**: Missing important sections
- **Low**: Unclear navigation labels
- **Info**: Well-structured navigation

## 3. Call-to-Action Analysis

### Checks
- Primary CTA presence
- CTA visibility
- CTA clarity
- Secondary CTAs
- CTA placement
- Action-oriented language

### Severity Rules
- **High**: No clear CTA
- **Medium**: Multiple competing CTAs
- **Low**: Vague CTA text
- **Info**: Clear, compelling CTA

## 4. Content Clarity

### Checks
- Value proposition clarity
- Benefit-oriented language
- Scannable content
- Visual hierarchy
- Readability
- Key information prominence

### Severity Rules
- **High**: No clear value proposition
- **Medium**: Dense, hard-to-scan content
- **Low**: Technical jargon without explanation
- **Info**: Clear, scannable content
